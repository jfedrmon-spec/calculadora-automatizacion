# Calculadora de automatización

Calcula cuánta plata y cuántos días laborales al año pierde un negocio haciendo tareas repetitivas a mano, y cuánto podría ahorrar automatizándolas.

**Pruébala:** https://jfedrmon-spec.github.io/calculadora-automatizacion

## Personalizar

Todo está en `index.html`. Al final del archivo, en `CONFIG`:

- `CTA_URL`: a dónde lleva el botón "Quiero automatizar esto". Para WhatsApp usa `https://wa.me/573001234567` (indicativo + número, sin espacios ni +).
- `CTA_ES_WHATSAPP`: si es `true`, el mensaje de WhatsApp llega escrito con los resultados de la persona.

Las tareas de ejemplo están en `EJEMPLO`.
